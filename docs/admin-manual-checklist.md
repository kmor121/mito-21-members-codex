# 管理画面手動確認チェックリスト

最小版の管理画面を短時間で目視確認するためのチェックリストです。

## 確認順
1. `/admin/dashboard`
2. `/admin/applications`
3. `/admin/fiscal-years`
4. `/admin/dues-management`
5. `/admin/organization-chart`
6. `/admin/newsletters`
7. `/admin/documents`
8. `/admin/settings`

## A1 ダッシュボード
- 画面が開く
- 未承認申込件数が表示される
- 会員数サマリーが表示される
- 当年度会費納入率が表示される
- 直近配信 5 件が表示される
- `入会申込確認` `会費管理` `配信管理` `設定` `会員一覧` に遷移できる

## A4 入会申込管理
- 画面が開く
- 申請中一覧が表示される
- 一覧を押すと詳細が表示される
- `承認` または `却下` が実行できる
- 実行後に一覧再取得される
- `ダッシュボード` `設定` `年度管理` `資料管理` `組織図管理` に遷移できる

## A8 年度管理
- 画面が開く
- 年度一覧が表示される
- `新規追加` で年度を保存できる
- 既存年度を選んで更新できる
- `現在年度にする` が実行できる
- 保存後に一覧再取得される
- `ダッシュボード` `設定` `会費管理` `資料管理` `組織図管理` に遷移できる

## A5 会費管理
- 画面が開く
- 年度セレクタが表示される
- 一覧に会員名、金額、ステータス、入金日が表示される
- 金額設定が保存できる
- 会費詳細の `納入状態` `入金日` `備考` を保存できる
- 保存後に一覧と集計が再取得される
- `ダッシュボード` `設定` `年度管理` `組織図管理` `配信管理` に遷移できる

## A6 組織図管理
- 画面が開く
- 年度セレクタが表示される
- 組織一覧が表示される
- 組織を新規保存できる
- 配属を新規保存できる
- 既存組織・既存配属を更新できる
- 削除ボタンが表示され、削除後に再取得される
- `ダッシュボード` `設定` `年度管理` `会費管理` `資料管理` に遷移できる

## A7 配信管理
- 画面が開く
- 配信一覧が表示される
- `新規作成` で詳細フォームが開く
- `タイトル` `本文` `channel` `status` `audience_type` が保存できる
- `対象件数を確認` が実行できる
- 添付表示名と添付 URL を保存できる
- 保存後に詳細再取得できる
- `ダッシュボード` `設定` `年度管理` `資料管理` `組織図管理` に遷移できる

## A10 資料管理
- 画面が開く
- 資料一覧が表示される
- `新規追加` で資料を保存できる
- `title` `doc_type` `fiscal_year_id` `content` `published` `sort_order` を保存できる
- `運用マニュアル` のとき `category` を保存できる
- 公開/非公開切替が動く
- 保存後に詳細再取得できる
- `ダッシュボード` `設定` `年度管理` `会費管理` `配信管理` `組織図管理` に遷移できる

## A9 設定
- 画面が開く
- A8 / A5 / A10 / A7 への導線が表示される
- `ダッシュボード` と `会員一覧` に戻れる
- 通知設定がプレースホルダであることが分かる

## 備考
- 認証/権限制御は未実装です
- Resend / LINE 接続は未実装です
- ブラウザ確認では、保存後に一覧または詳細が再読込されることを優先して確認します
